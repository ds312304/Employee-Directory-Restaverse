# Employee Directory – Frontend

This is the frontend application for the Employee Directory Search System, built using **React + Vite**.

The frontend focuses on **performance-aware search**, clean component structure, and a polished user experience.

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios

---

### 1. Install Dependencies
```bash
npm install

### 2. Environment Configuration
